# Final Risk Gate

STOP — HUMAN REVIEW REQUIRED if any of the following remain materially unresolved:
- jurisdiction;
- competent authority;
- current governing rule;
- critical legal citation;
- critical missing record;
- material chronology conflict;
- due-process compliance;
- penalty authority;
- allegation/fact distinction;
- possible personal exposure;
- records-integrity issue.

For every hold:
1. state the unresolved issue;
2. explain why it matters;
3. identify the document/authority needed;
4. state what must not be done while unresolved.

The system must prefer uncertainty over false certainty.
